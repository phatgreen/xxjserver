## 1. TONG QUAN GIA LAP

### 1.1 Muc dich
Gia lap 200 nhan vat trai nghiem **toi da tat ca 24 tinh nang** cua game Tam Tien Ky, tu tao nhan vat den khi dat cap do toi da (4,350) va hoan thanh moi he thong.

### 1.2 Cau truc gia lap
- **Tong so tinh nang:** 24 he thong
- **Tong so cap do:** 4,350 (87 canh gioi x 50 cap)
- **Tong so dot pha:** 870 (87 canh gioi x 10 giai doan)
- **Tang thap:** 150 tang
- **O trang bi:** 16 o
- **Ky nang vo cong:** 20 ky nang
- **Nhiem vu:** 5 loai (Ngay/Tuan/Thang/Thanh Tuu/Chinh Tuyen)

### 1.3 Phuong phap
- Moi nhan vat duoc gia lap doc lap voi RNG (random number generator)
- Thoi gian tinh theo phut, quy doi sang gio/ngay/thang
- Tien te tinh theo don vi game (Linh Thach - LT, Ma Thach - MT)
- Ket qua la **gia tri trung binh** cua 200 nhan vat

## 8. PHU LUC CONG THUC

### 8.1 EXP Rate
```
EXP = cap * VIP * multiplier * min(1.3, 1 + cp_absorb/100) * min(1.3, 1 + lc_absorb/100)
```

### 8.2 Ty Le Dot Pha
```
ty_le = max(5, 75 - cap*0.6 - canh*3 + giai_doan_bonus + trang_bi_bonus)
```

### 8.3 Cong Thuc Chien Luc
```
Chien Luc = ATK*10 + DEF*8 + HP + CRIT*30 + HutMau*25 + ThienPhu*50 + MayMan*10 + NeTranh*10 + ThanTrang*Power
```

### 8.4 Toc Do Tu Luyen
```
toc_do = cap * VIP * multiplier * min(1.3, 1 + cong_phap_absorb/100) * min(1.3, 1 + linh_can_absorb/100)
```

### 8.5 Chi Phi Dich Chuyen
```
chi_phi = cap * 12 + 500 (Linh Thach)
```
